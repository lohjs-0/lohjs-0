### `01 // THE OPERATOR`

<img src="a1c8e5309f6622bb37754c13ebc35242.jpg" align="right" width="220" alt="Profile artwork">

**`IDENTITY: SOFTWARE DEVELOPMENT STUDENT`**

**`FOCUS: BACK-END ENGINEERING & CYBERSECURITY`**

I'm a Software Development student interested in what happens beneath the surface of technology.

My primary focus is **back-end development**, particularly **C#, ASP.NET Core, API architecture, databases, and application security**. I also work with front-end technologies to understand how systems connect from end to end.

Beyond application development, I explore **cybersecurity, digital forensics, Linux, networking, and operating system internals**.

Recently, I've been expanding my interests toward **C++, digital electronics, embedded systems, and hardware-level security**, exploring the boundaries between software and physical systems.

I enjoy understanding not only how something works, but also **why it works, where it fails, and how it can be improved**.

<br>

**`CURRENT AREAS OF EXPLORATION`**

- **Software Engineering:** Back-end architecture, REST APIs, databases, and system design.
- **Cybersecurity:** Application security, network analysis, and digital forensics.
- **Systems:** Linux, operating systems, virtualization, and system internals.
- **Hardware:** Digital logic, KiCad, microcontrollers, and embedded systems.
- **Research:** Code obfuscation, reverse engineering concepts, and hardware security.
